# Implementation Notes

This folder is a planning baseline. The first implementation should add and maintain:
- `ARCHITECTURE.md`: interfaces, data flow, failure handling, and state transitions.
- `CONFIGURATION.md`: schema, precedence, environment variables, config paths, and examples.
- `SECURITY.md`: threat model, tool permissions, workspace boundary assumptions, and reporting process.
- `DEVELOPMENT.md`: verified setup, test, lint, build, and release commands.

Do not document a capability as supported until it is implemented and covered by tests.
